# ideogram-mcp

Generate and edit images and video from Claude Code with every model Ideogram sells, through one API key.

## Install

```bash
claude mcp add --scope user ideogram -e IDEOGRAM_API_KEY=your-api-key -- npx -y @qmediat.io/ideogram-mcp
```

## Try it

```text
Use ideogram to generate a poster for a jazz night, 3:4
```

## Tools

| Group | What | Tools |
|---|---|--:|
| Images | Generate, edit, remix, reframe, upscale, describe, backgrounds | 11 |
| Video | From a prompt, a start image, reference clips | 3 |
| Ads | Translate, resize, vary | 3 |
| Product photos | Recolor, swap materials, ghost mannequin, poses, sketch to render | 5 |
| Layers and masks | Split a design into layers, remove logos, snap masks | 3 |
| Prompts and provenance | Rewrite a prompt, check an image's origin | 2 |
| Price | A call's price, before it runs | 1 |
| Account | Usage, invoices, API keys | 3 |
| Custom models | Datasets, training, your models | 4 |
| Any operation | Collect a job, list or call any operation | 3 |
